# Локальные ресурсы симулятора

`models/` — независимые копии моделей, доступные Gazebo через `model://имя`.
`worlds/` — SDF-файлы миров. В контейнере эти папки расположены в `/work/assets`.
Изменения сохраняются в этом Git-репозитории; автоматической синхронизации
с исходными репозиториями нет.

## Jetbot

Скопирован 2026-09-20 из `/data/WORK/repo/jetbot_ros_gazebo/models/jetbot`.
Исходный проект: https://github.com/KirillMouraviev/jetbot_ros_gazebo
Скопированы все 17 файлов, включая meshes и альтернативные SDF.

Для переносимости в локальной копии:
- Удалены пустые строки перед XML-декларациями в SDF.
- Абсолютные пути meshes в альтернативных SDF заменены на
  `model://jetbot/meshes/<имя файла>`.

Активный файл выбирается через `model.config`; сейчас это `model.sdf`.
Исходники сторонней модели сохраняют условия лицензирования авторов.

## Склад

`worlds/warehouse/jetbot_warehouse.sdf` — готовый склад с Jetbot.
Модели окружения также скопированы в `models/`; их версии и источники
указаны в [README склада](worlds/warehouse/README.md). Запуск: `make warehouse`.

Исправление локального `models/jetbot/model.sdf`: цилиндр коллизии камеры
перенесён непосредственно в `<geometry>`; ошибочная обёртка `<mesh>` удалена.
Размеры и положение цилиндра сохранены.
